# 4) Tableaux des Primitives Usuelles

| Fonction à intégrer $f(x)$  | Primitive $F(x) + C$       |
| :-------------------------- | :------------------------- |
| $x^n$                       | $\frac{x^{n+1}}{n+1}$      |
| $\frac{1}{x}$               | $\ln(\vert{}x\vert{})$     |
| $e^x$                       | $e^x$                      |
| $a^x$                       | $\frac{a^x}{\ln(a)}$       |
| $\cos(x)$                   | $\sin(x)$                  |
| $\sin(x)$                   | $-\cos(x)$                 |
| $\frac{1}{\cos^2(x)}$       | $\tan(x)$                  |
| $\frac{1}{\sin^2(x)}$       | $\frac{-1}{\tan(x)}$       |
| $\operatorname{ch}(x)$      | $\operatorname{sh}(x)$     |
| $\operatorname{sh}(x)$      | $\operatorname{ch}(x)$     |
| $\frac{1}{ch^2(x)}$         | $th(x)$                    |
| $\frac{1}{\sqrt{1 - x^2}}$  | $\arcsin(x)$               |
| $\frac{-1}{\sqrt{1 - x^2}}$ | $\arccos(x)$               |
| $\frac{1}{1 + x^2}$         | $\arctan(x)$               |
| $\frac{1}{1 - x^2}$         | $\operatorname{arg th}(x)$ |
| $\frac{1}{\sqrt{x^2 + 1}}$  | $\operatorname{arg sh}(x)$ |
| $\frac{1}{\sqrt{x^2 - 1}}$  | $\operatorname{arg ch}(x)$ |
