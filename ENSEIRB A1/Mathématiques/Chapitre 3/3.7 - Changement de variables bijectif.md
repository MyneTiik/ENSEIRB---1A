# 7) Changement de variables bijectif

### a) Rappel sur la bijectivité
Une fonction est bijective si :
1. $f(a) = f(b) \implies a = b$ (la fonction est monotone, elle ne "stagne" pas). 
2. Si $C$ appartient à l'intervalle considéré, alors il existe un $x_n$ tel que $C = f(x_n)$. 

### b) Principes
Soit $F(x) = \int f(x) \, dx \iff F'(x) = f(x)$. 
Si on pose $t \mapsto \varphi(t) = x$ qui définit une bijection, la fonction réciproque est $x \mapsto \varphi^{-1}(x) = t$. 
On a alors : 
$$F(\varphi(t)) = \int f(\varphi(t))\varphi'(t) \, dt$$
### c) Exemple complet (Fraction rationnelle)
Intégrer $f(x) = \frac{2x+3}{x^2+2x+5}$. 
On sépare la fraction pour faire apparaître la dérivée du dénominateur ($2x+2$) :
$$\int \frac{2x+3}{x^2+2x+5} \, dx = \int \frac{2x+2}{x^2+2x+5} \, dx + \int \frac{1}{x^2+2x+5} \, dx$$  

* Le premier terme donne directement une forme $\frac{u'}{u} \implies \ln(x^2+2x+5)$. 
* Pour le second terme, on utilise la **forme canonique** du dénominateur : 
  $$x^2+2x+5 = (x+1)^2 + 4 = 4\left(\frac{(x+1)^2}{4} + 1\right)$$ 
  Ce qui nous donne à intégrer : $\int \frac{1}{4\left(\left(\frac{x+1}{2}\right)^2 + 1\right)} \, dx$ 

**Application du changement de variable :** 
* On pose $X = \frac{x+1}{2}$ 
* En dérivant : $\frac{dX}{dx} = \frac{1}{2} \implies dx = 2 \, dX$ 
* On remplace dans l'intégrale : $\int \frac{1}{4(X^2+1)} \, 2 \, dX = \frac{1}{2} \int \frac{1}{X^2+1} \, dX$ 
*(Ce qui permet ensuite de retomber sur une primitive connue en $\arctan$)*.
