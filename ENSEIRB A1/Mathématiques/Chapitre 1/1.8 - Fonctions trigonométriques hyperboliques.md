# h) Fonctions trigonométriques hyperboliques

Par analogie avec le cercle trigonométrique, on définit les fonctions hyperboliques à l'aide de l'exponentielle réelle :
* **Cosinus hyperbolique :** $\operatorname{ch}(x) = \frac{e^x + e^{-x}}{2}$
* **Sinus hyperbolique :** $\operatorname{sh}(x) = \frac{e^x - e^{-x}}{2}$
